# Data directory

Obtain each dataset from its official provider and place it under this directory, or pass an arbitrary local path with `--input-dir`.

Suggested layout:

```text
data/
  ADNI/
  ABIDE/
  HCP-WM/
  OASIS/
  PPMI/
  HAR/
    F3D.mat
    HDM14.mat
    UTK.mat
  florence_metadata/
    Florence_dataset_WorldCoordinates.txt
```
